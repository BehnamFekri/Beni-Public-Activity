Public activity log and portfolio updates by **Behnam Fekri**.

- Show ongoing activity
- Document public-facing milestones
- Keep GitHub profile active and professional

## Structure

- `activity/` ← Short public updates
- `milestones/` ← Important achievements
- `portfolio/` ← Selected public projects overview

## Security Rules (Strict)

**This repository must NEVER contain sensitive information.**

Absolutely forbidden:
- Passwords
- Tokens
- API Keys
- Secrets
- Authentication credentials
- Private source code
- Confidential project details
- Any other security-related information

Only non-sensitive summaries and public achievements are allowed.
